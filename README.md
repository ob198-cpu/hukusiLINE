# トライズ大通 LINE問い合わせ管理

Node.js 24以上で動くLINEボットと管理画面です。

## GitHub Pagesで回答テスト

[公開画面](https://ob198-cpu.github.io/hukusiLINE/)の「回答テスト」で問い合わせを入力し、「判定する」を押すと、処理・分類・確信度・理由・返信を確認できます。このブラウザに保存した設定・FAQ・事業所情報と、既存の回答条件を使用します。変更した設定は従来どおり各画面で保存してから試してください。

これはルール回答のテストです。OpenAIの生成回答・LINE送受信には接続せず、テスト入力・結果を会話履歴へ保存しません。自動回答停止、営業時間、緊急、利用中・関係機関の職員引継ぎなどの既存条件は維持します。OpenAIモードで既存情報に該当しない質問は、未接続時の従来の職員確認判定になり、生成回答を装いません。

2026-10-14に公開用の回答テスト経路を追加。サーバーの純粋なルール3モジュールを変更せず公開用ビルドに含め、保存しないプレビューだけをブラウザ内で実行します。OpenAI・LINE接続テストは従来の無効状態を維持し、Nodeサーバー・LINE Webhook・DB・秘密情報・初期設定は変更しません。新15件＋既存22件、計37件の自動テストが合格。配布対象13ファイルの安全監査と元ルール・設定の維持も確認しています。

## 起動

1. `.env.example`を`.env`にコピーし、必要な接続情報を設定します。
2. `npm start`で起動します。
3. `http://127.0.0.1:8790/`を開きます。

初回起動時にトライズ大通の基礎情報・入力項目を読み込みます。FAQは0件です。テスト用の仮設定7項目を含み、`offices[].testData`に記録されています。既存の設定DBは上書きしません。

## 保存と秘密情報

設定・会話は`data/line-inquiries.db`に保存されます。会話履歴、APIキー、LINEトークン、実際の.env、ログ、バックアップはこのリポジトリに含めていません。

`DEMO_MODE=true`ではLINEへの実送信は行いません。実接続には接続情報と公開HTTPSのWebhookが必要です。

## 公開状況

このリポジトリへの登録だけではWebサーバーは公開されません。GitHub PagesだけではNode.js・SQLite・LINE Webhookを実行できません。

現状の管理画面はPC内専用で、127.0.0.1に待ち受け、外部・転送経由アクセスを拒否します。パスワード認証はありません。外部に管理画面を公開するには、公開先に合わせたアクセス制限と永続ストレージの構成が必要です。

`webhook-gateway.mjs`は127.0.0.1:8791でLINE受信だけを中継します。管理画面は中継しません。常設サーバーへの配備・公開URLは未設定です。
